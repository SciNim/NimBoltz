* NimBoltz

Electron transport in gas mixtures: [[https://magboltz.web.cern.ch/magboltz/][Magboltz]] 11.21 (S. Biagi), the
reference Monte Carlo program for drift velocities, diffusion, mean
energies and Townsend coefficients of electrons in gases, ported to Nim.

- The same input decks and the same printout as Magboltz, all 61 gases
  (and the 19 empty slots of Magboltz), all field geometries, the gas at
  0 K or with thermal motion, Penning transfers, the Townsend analyses.
- Faster than Magboltz and than [[https://gitlab.cern.ch/garfield/magboltzpp][Magboltz++]], on one thread and more so on
  many, on NVIDIA GPUs and in a web page (WebAssembly, WebGPU).
- A library: a gas mixture and the fields in, the results out as values
  with errors and units.
- 61 defects of Magboltz 11.21 fixed, each reported with a reproduction
  (see [[Defects of Magboltz]]).

** Two modes

| Mode                    | How                     | What                                                                                                 |
|-------------------------+-------------------------+------------------------------------------------------------------------------------------------------|
| Default                 |                         | many independent electrons, exact bounds of the collision frequency, all cores: Magboltz's results within errors |
| Magboltz, bit for bit   | ~NIMBOLTZ_FORTRAN=1~    | one electron, Magboltz's methods and random numbers, one thread: Magboltz's printout, number for number |

The default mode gives the same physics with other estimators: the drift
run follows many electrons ("walkers") instead of one long trajectory,
and every free flight uses an exact upper bound of the collision
frequency over short time windows instead of Magboltz's coarse one, so
far fewer null collisions are drawn. Its results agree with Magboltz's
within the errors, and its errors are honest: Magboltz underestimates
some of its own (diffusion by 2–5 times, attachment in CCl₄ and SF₆ by up
to 16 times).

The bit-for-bit mode is there to cross-check: with the same deck it prints
what Magboltz 11.21 prints (with the defects below fixed in both), digit
for digit, which the regression tests check on 96 decks.

** Building and running

Nim 2.2 or later, and the packages of ~NimBoltz.nimble~.

#+begin_src sh
nim c -d:release -o:nimboltz-mb src/nimboltz/magboltz_main.nim
./nimboltz-mb < deck.in > deck.out          # a Magboltz deck, Magboltz's printout
NIMBOLTZ_FORTRAN=1 ./nimboltz-mb < deck.in   # Magboltz 11.21, bit for bit
#+end_src

| Variable                 | Effect                                                                             |
|--------------------------+------------------------------------------------------------------------------------|
| ~NIMBOLTZ_FORTRAN=1~     | Magboltz bit for bit (see above)                                                   |
| ~NIMBOLTZ_THREADS=n~     | n threads instead of all cores                                                     |
| ~NIMBOLTZ_SEED=n~        | another seed (Magboltz's is 54217137)                                              |
| ~NIMBOLTZ_WALKERS=…~     | ~cpu[:n]~ (default: 100 per thread), ~gpu[:n]~ or ~gpu32[:n]~ (a GPU build, below)  |
| ~NIMBOLTZ_RNG=…~         | ~xoshiro~ (default: xoshiro256+, on GPUs xoshiro128) or ~ranmar~ (RM48), walkers    |
| ~NIMBOLTZ_TIMING=1~      | the time of each step of a deck on stderr                                          |

** As a library

#+begin_src nim
import nimboltz/api

let r = simulate(Setup(mixture: @[(argon, 90.0), (carbonDioxide, 10.0)],
                       efield: 500.0.V•cm⁻¹, collisions: 4_000_000))
echo r.velocity.z               # 41.1 ± 0.122 MicroMeter•NanoSecond⁻¹
echo r.spread(r.transverse)     # √(2D/v), per √cm
#+end_src

A ~Setup~ is one Magboltz deck (gases and shares, temperature, pressure,
E, B and its angle, collisions, Penning transfers, thermal motion);
~Setup.fortran~ selects the bit-for-bit mode. ~Results~ has the drift
velocity, the diffusion tensor, the mean energy, the Townsend and
attachment coefficients and the results of the Townsend analyses, each
with its error, plus the collision frequencies by process and the energy
distribution. See ~src/nimboltz/api.nim~.

** Speed

Whole decks of the regression set (~tests/regress/decks~, 4·10⁷
collisions, Townsend analyses where Magboltz runs them), one thread each,
15 decks side by side on a Ryzen 9 5950X; CPU seconds:

| deck                                  | default | Magboltz++ | bit for bit | Magboltz 11.21 |
|---------------------------------------+---------+------------+-------------+----------------|
| Ar/CO₂ 90/10, 0 K (arco2_nob_t0)      |     8.9 |       13.9 |        22.5 |           28.0 |
| Ar/CO₂ 90/10, B ⊥ E (arco2_bperp_t0)  |    11.0 |       13.5 |        32.2 |           38.7 |
| CO₂, thermal (pure_co2_t1)            |    10.3 |       16.4 |        17.4 |           20.5 |
| CF₄ (gas01)                           |    15.8 |       98.3 |       147.1 |          191.2 |
| H₂ (gas21)                            |    11.7 |       71.5 |        40.5 |           51.0 |
| air, Townsend (hi_air_t0)             |   203.2 |      414.8 |       890.0 |          992.5 |
| Ne/CO₂, Townsend (penning_neco2_t0)   |    30.9 |       42.7 |        46.0 |           52.0 |

Over 90 decks (six left out where the programs do not run the same
thing: Magboltz++ stops early, or MB-58 changes the physics) the default
mode is 2.3 times as fast as Magboltz++ (geometric mean; median 1.8,
slowest deck 1.08: pure argon), 2.7 times as fast as the bit-for-bit mode
and 3.2 times as fast as Magboltz 11.21 (gfortran -O2); in total 28 CPU
minutes against 89, 92 and 113. Magboltz++ skips the Townsend analyses
below |α − η| = 25 /cm; its times above are of a build with Magboltz's
limit (5). On all cores (the default) the walkers and the avalanches run
in parallel: arco2_nob_t0 takes 8.5 s on one thread, 1.6 s on 32.

Where the time goes: Magboltz's free flight takes 5–10 null collisions
per real one; the walkers bound the collision frequency exactly over
short windows of time (~0.1 null collisions per real one), draw angles
without trigonometric functions, and take their random numbers from
xoshiro256+ (Ranmar's in the bit-for-bit mode). See ~docs/DESIGN.md~.

** GPUs and the web

- NVIDIA GPUs: build with ~-d:nimboltzGpu --path:<tattletale>~ (Crucible,
  the Nim-to-GPU compiler of [[https://github.com/mratsim/tattletale][tattletale]]) and run with
  ~NIMBOLTZ_WALKERS=gpu~ (or ~gpu32~ in single precision: on an RTX 3090
  1.0–1.8 G collisions/s, double precision 0.12–0.48).
- A web page (~web/~): NimBoltz compiled to WebAssembly, on all cores of
  the browser's machine and on its GPU through WebGPU. See ~web/README.md~.

** Agreement with Magboltz

- ~tests/regress~: the bit-for-bit mode against the Fortran program, 96
  decks (all geometries, thermal motion, Penning transfers, analyses),
  byte for byte.
- ~tests/stat~: the default mode against the Fortran program, every
  printed result within its errors, the errors measured over several
  seeds where Magboltz's are too small.
- ~tests/gasengine~, ~tests/gasdump~: the collision tables of all gases
  against Magboltz's.
- ~tests/unit~, ~tests/ensemble~, ~tests/gpu~, ~tests/wasm~: the library,
  the walkers, CPU against GPU walkers.

How it is built and why: ~docs/DESIGN.md~.

** Defects of Magboltz

Porting Magboltz line by line, comparing every table bit for bit and then
comparing with Magboltz++ found 61 defects in Magboltz 11.21 (MB-01 to
MB-61): wrong array indices, typos in constants, levels skipped or
counted twice, a mass off by 81 amu, energy lost twice, uninitialised
values, 32-bit overflows. Each is fixed by its evident intent in NimBoltz
and on the branch ~fixes~ of the Magboltz fork, one commit each, with a
report (~bugs/README.md~ there: what, where, its effect on results, a
reproduction), and 15 open questions where the intent is not clear
(~bugs/QUESTIONS.md~). Where Magboltz has a defect, NimBoltz's results
are those of the fixed Magboltz.

** The Magboltz interfacer

The first NimBoltz wrote Magboltz decks and ran the Fortran program on
them, several in parallel; it is still here (~nimboltz.nim~):

#+begin_src nim
import nimboltz
let gases = initGases([("argon", 97.7), ("isobutane", 2.3)])
let mb = initMagboltz(gases, 1050.mbar, 300.K, 60.kV•cm⁻¹, nMax = 10,
                      usePenning = true, gasMotionThermal = true)
runMagboltz(mb)        # or runMagboltz([mb1, mb2, ...]) in parallel
#+end_src

It needs ~magboltz~ on the PATH:

#+begin_src sh
wget https://magboltz.web.cern.ch/magboltz/magboltz-11.21.f
gfortran -O3 -o magboltz magboltz-11.21.f
#+end_src

The tests compare with the Fortran program too (~MAGBOLTZ_SRC~, default
~~/src/Magboltz/magboltz-11.21.f~).
